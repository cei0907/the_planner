# The Planner 개발 문서

이 폴더는 `Documents/The_Planner_V2.html`을 구현 가능한 개발 명세로 바꾸기 위한 문서 묶음이다.

목표는 두 가지다.

1. 아주 날카로운 OOP 기반으로 시스템을 설계한다.
2. 추후 AI에게 이 문서들만 전달해도 같은 방향의 프로그램을 만들 수 있게 한다.

## 문서 구조

- `00-ai-handoff.md`: AI 또는 새 개발자가 가장 먼저 읽어야 할 인계 문서
- `01-domain-language.md`: 제품의 핵심 언어와 개념 정의
- `02-object-model.md`: 주요 객체, 책임, 금지사항
- `03-object-pseudocode.md`: 객체별 슈도코드
- `04-domain-rules.md`: 완료, 반복, 진행률, Plan 연결 규칙
- `05-implementation-roadmap.md`: 개발 순서와 산출물
