Architectural Evaluation

제스처 숨김의 한계와 상시 노출형 삼각 축 뷰포트 전환 설계

기획자이자 유저로서 지적하신 **"새로운 Task 계획과 스케줄 열람의 상시 접근성 확보"**는 전적으로 정당한 요구사항입니다. 기존 제안이었던 줌 인/아웃 및 풀다운 제스처는 화면을 깨끗하게 유지할 수는 있으나, 하루에도 수십 번 명확한 목적(계획 수정, 일정 파악)을 가지고 앱을 켜는 헤비 유저에게는 치명적인 '기능 발견 차단(UX Barrier)'으로 작용합니다.

동의 및 전면 수정 명세: 삼각 축 제어 패널(Triad persistent bar)

첫 화면 하단에 묵직하고 투명한 **영롱한 글래스 내비게이션 바**를 상시 노출형으로 강제 배치했습니다. 유저는 앱을 켜자마자 0초 만에 자신의 인지 상태에 맞는 완벽한 물리적 전역 진입점을 획득합니다.

핵심 진입점 (Tab) 유저의 즉각적 심리 상태 데이터 및 화면의 역할
🛠️ 계획 만들기 (Converter) "갑자기 좋은 영감이 떠올랐어, 꿈을 조각내고 싶어" Task Tree 원본 데이터베이스 핸들링. 인박스 포착 영역 가동.
🎯 오늘 집중 (Focus) "지금 당장 내가 집중해서 쳐내야 할 조각이 뭐지?" 현재 시간대 Plan에 배치된 단일 PlanTask 카드 덱 렌더링 (기본 메인).
🗓️ 계획 보기 (Schedule) "이번 주, 이번 달 전체 스케줄 흐름을 확인하고 싶어" 일/주/월/년 세그먼트를 보유한 카드형 캘린더 타임라인 활성화.

🔎 날짜 지난 미완료 조각의 처리 규칙 (공학적 고찰)

귀하가 동의하신 대로, 시간이 경과한 미완료 PlanTask들은 오늘 자 집중(Focus) 카드 덱이나 오늘 자 스케줄 화면에서 **어떠한 자동 이월(Auto-carryover)도 없이 깨끗하게 소거**됩니다. 실패의 기록을 고착화하여 인지적 부하를 차단하되, 좌측 모바일 프레임의 **[계획 만들기]** 탭 내부에 상시 보관되므로 유저는 언제든 안정적으로 구조를 확인하고 다음 시간 영토로 재배치할 수 있는 주도권을 획득합니다.
